# Supplied domain covers

The four original PNG uploads were supplied by the repository owner for this
prototype, in order: Tech, Research, Management, Design. They contain fan art and
third-party game characters/titles. Their original authors/licenses have not
been verified; no ACM ownership or endorsement is asserted.

`src/lib/domain-cover-art.ts` defines the crop once for the console, case and
disc label. Crops exclude screenshot sidebars and the cursor at the left edge of
the last two uploads. Original files remain intact. CC retains its original
editable SVG world. No generated replacement artwork is used.
